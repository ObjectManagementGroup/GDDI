# List of GDDI Vendor ID's

Version: 2025.04.11

Date:    2025-04-11


Maintained by members of the OMG Space Domain Task Force (SDTF) at
https://www.omg.org/space/


New GDDI vendors are welcome. If a vendor finds that one of the standard
GDDI types is insufficient for a specific use case, then GDDI vendor-
specific metadata can be used along with the Vendor ID as described in
the GDDI standard, located here: https://www.omg.org/spec/GDDI


```
# GDDI Vendors: Sorted by the Vendor ID with range 0 - 255 (decimal).

#ID  VendorName

000  (Reserved)

002  Sphinx Defense, Inc.
255  (Reserved)
```
